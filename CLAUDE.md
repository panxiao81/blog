## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo with one root `CONTEXT.md` and root `docs/adr/`. See `docs/agents/domain.md`.

### Design context

Project-level strategic design context lives in `PRODUCT.md`.
Project-level visual system context lives in `DESIGN.md`.
Impeccable live-panel component and token metadata lives in `.impeccable/design.json`.
