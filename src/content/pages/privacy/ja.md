これは個人ブログです。あなたについての情報はできるだけ集めないようにしており、個人を
識別しうる部分（アクセス解析と広告）は、あなたが同意するまで動作しません。このページ
では、何が・誰によって収集されるのか、そしてその選択をいつでも変更する方法を説明し
ます。

## Cookie と同意

初回アクセス時、アクセス解析と広告に関するストレージは **デフォルトで拒否** されて
います（Google Consent Mode による）。同意バナーの **同意する** を押すまで、これらに
は何も読み込まれません。**断る** を押した場合でも、サイトはそのまま動作し、これらの
サービスは無効のままです。

選択内容はブラウザのローカルストレージに保存されるため、ページごとに何度も尋ねられる
ことはありません。フッターおよびこのページ下部の **プライバシー設定** ボタンから、
いつでも変更できます。

## 収集する情報

- **アクセス解析 — Google Analytics。** 同意した場合のみ有効になります。閲覧したページ、
  おおよその地域、デバイス／ブラウザの種類など、匿名の利用状況を記録し、どんな記事が
  読まれているかを把握するために使います。個人を特定する目的では使用しません。
- **広告 — Google AdSense。** 同意した場合のみ有効になります。Google は広告の表示と
  計測のために Cookie を設定することがあり、許可された範囲でパーソナライズ広告も含まれ
  ます。広告は一覧ページと記事の末尾にのみ表示されます。
- **コメント — Utterances / GitHub。** コメントは Utterances によって提供され、公開の
  GitHub リポジトリに Issue として保存されます。コメントの投稿には GitHub アカウントと
  Utterances アプリの認可が必要で、コメントと GitHub のユーザー名は公開されます。この
  部分は GitHub が自社のプライバシーステートメントに基づいて取り扱います。
- **設定。** テーマの選択と同意の選択は、ブラウザのローカルストレージにのみ保存され、
  サーバーに送信されることはありません。
- **ホスティングのログ。** サイトは Cloudflare を通じて配信され、ページの配信と不正
  利用の防止のために標準的なリクエストデータ（IP アドレスなど）が処理されます。

## 第三者サービス

これらのサービスには、それぞれ独自のプライバシーポリシーがあります：

- [Google プライバシーポリシー](https://policies.google.com/privacy)、および
  [Google のサービスを使用するサイトから得た情報の利用について](https://policies.google.com/technologies/partner-sites)
- [GitHub プライバシーステートメント](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)
- [Cloudflare プライバシーポリシー](https://www.cloudflare.com/privacypolicy/)

Google の広告のパーソナライズは
[Google 広告設定](https://adssettings.google.com) で管理できます。

## あなたの選択

- **プライバシー設定** から、アクセス解析と広告をいつでも拒否できます。
- ブラウザの Cookie とローカルストレージを消去すると、すべての選択がリセットされます。
- 公開された GitHub の記録を残したくない場合は、コメントを控えてください。

## 変更について

本ポリシーは、サイトの変更に応じて更新されることがあります。最新版は冒頭の日付で示し
ます。
