这是一个个人博客。我尽量少收集关于你的信息，凡是可能识别你身份的部分（统计分析与
广告）在你同意之前都不会启用。本页说明收集了哪些信息、由谁收集，以及如何随时更改你
的选择。

## Cookie 与同意

你首次访问时，统计分析与广告相关的存储**默认处于拒绝状态**（通过 Google Consent
Mode 实现）。在你点击同意横幅上的**接受**之前，它们不会加载任何内容。如果你点击
**拒绝**，网站照常工作，这些服务保持关闭。

你的选择会保存在浏览器的本地存储中，因此不会在每个页面反复询问。你可以随时通过页脚
以及本页底部的**隐私设置**按钮更改它。

## 收集哪些信息

- **统计分析 —— Google Analytics。** 仅在你接受后启用。它记录匿名的使用情况，例如你
  浏览的页面、大致位置以及设备/浏览器类型，让我了解大家在读什么。它不会用于识别你的
  个人身份。
- **广告 —— Google AdSense。** 仅在你接受后启用。Google 可能设置 Cookie 来展示和衡量
  广告，在允许的情况下包括个性化广告。广告只出现在列表页以及文章末尾。
- **评论 —— Utterances / GitHub。** 评论由 Utterances 提供，以 Issue 形式存储在一个
  公开的 GitHub 仓库中。发表评论需要 GitHub 账号并授权 Utterances 应用；你的评论与
  GitHub 用户名将公开可见。这部分由 GitHub 依据其自有隐私声明处理。
- **偏好设置。** 你的主题选择与同意选择仅保存在浏览器的本地存储中，绝不会发送到
  服务器。
- **托管日志。** 网站通过 Cloudflare 提供服务，它会处理标准的请求数据（例如 IP
  地址）以交付页面并防止滥用。

## 第三方服务

这些服务有各自的隐私政策：

- [Google 隐私政策](https://policies.google.com/privacy)，以及
  [Google 如何使用来自其合作网站的信息](https://policies.google.com/technologies/partner-sites)
- [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)
- [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)

你可以在 [Google 广告设置](https://adssettings.google.com) 中管理 Google 的广告
个性化。

## 你的选择

- 随时通过**隐私设置**拒绝统计分析与广告。
- 清除浏览器的 Cookie 与本地存储即可重置所有选择。
- 如果你不希望留下公开的 GitHub 记录，可以不发表评论。

## 变更

本政策可能随网站变化而更新。顶部的日期表示最新版本。
