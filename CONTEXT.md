# Blog

A personal publishing site for essays, notes, and portfolio content. It exists to publish authored writing with a plain presentation and multilingual reader experience.

## Language

**Post**:
A published piece of writing with its own title, body, and metadata.
_Avoid_: Article, entry

**Locale**:
A reader-facing language variant of the site.
_Avoid_: Language pack, translation mode

**Source Post**:
The author-written version of a Post in its original language.
_Avoid_: Canonical post, master post, origin post

**Translated Post**:
A localized version of a Source Post for a different Locale. It may be human-written or machine-generated, but it is still presented as a Post.
_Avoid_: Mirror post, duplicate post

**Post Slug**:
The URL identifier for a Post, derived from its Markdown filename and kept the same across Locales.
_Avoid_: Localized permalink, route alias

**Excerpt Break**:
An in-body marker that separates the preview excerpt of a Post from the rest of its content.
_Avoid_: Tag, summary field

**Auto-Translated Post**:
A Translated Post generated by a machine rather than authored directly by the writer.
_Avoid_: AI post, generated duplicate

**Translation Notice**:
A reader-facing disclosure that a Post was translated automatically or that the reader is being sent to a Source Post in another Locale.
_Avoid_: Warning, disclaimer badge, language alert

**Translation State**:
Metadata that records whether a localized Post is draft, auto-translated, reviewed, or treated as a normal published translation.
_Avoid_: Hidden flag, implicit status

**Comment Key**:
A stable locale-agnostic pathname-style identifier, such as `/posts/{slug}/`, used to attach one shared comment thread to a Post across Locales and route changes.
_Avoid_: Locale-specific thread ID, visible URL as identity

**License Policy**:
A shared default reuse or copyright notice for Posts, typically presented as a translated label plus an external license link, with the option to override it per post.
_Avoid_: Hidden default, site-only license

**Asset Fallback**:
A content-asset rule where post-specific files are co-located with a Post when practical, but shared or reused assets may live in a common location.
_Avoid_: Forced global assets, forced per-post duplication

**Locale Archive**:
The listing page for Posts available in a specific Locale.
_Avoid_: Language feed, translated archive

**Source Post Placeholder**:
A list entry shown in a Locale when the localized Post does not exist yet, linking readers to the Source Post in another language.
_Avoid_: Fake translation, hidden fallback

**About**:
A standalone page on the site that presents the author’s personal profile, selected work, background, and links.
_Avoid_: Portfolio, showcase, works page, blog portfolio, portfolio section

**Privacy Page**:
A standalone page that explains the site’s use of analytics, ads, and external services.
_Avoid_: Hidden policy, implied disclosure

**Consent Choice**:
A reader’s persisted privacy selection, stored in the browser and used to control consent-dependent services.
_Avoid_: Session-only choice, hidden default

**Privacy Settings**:
A reader-facing control that reopens consent choices after the initial banner decision.
_Avoid_: One-time-only consent, hidden reset

**Theme Preference**:
A reader-selected display mode with three states: light, dark, or follow-system.
_Avoid_: Binary theme toggle, hidden theme mode

**Tag**:
A locale-scoped label attached to content for lightweight grouping and discovery.
_Avoid_: Global topic, universal label

**Category**:
A locale-scoped classification attached to content for broader grouping than a Tag.
_Avoid_: Global section, universal category

**Series**:
A locale-scoped sequence of related Posts that belong to the same ongoing set.
_Avoid_: Global series, hidden collection

**Locale-Prefixed Route**:
A URL structure where every page lives under an explicit Locale segment.
_Avoid_: Root-locale route, implicit language URL

**Language Preference**:
The Locale the reader chooses explicitly or the site infers for first-time entry.
_Avoid_: Default language, automatic locale

**Locale-Aware Font Stack**:
A font stack chosen for the language of the rendered content rather than a single stack shared by all Locales.
_Avoid_: Universal font stack, one-font-for-all

**Main Navigation**:
The small hard-coded set of top-level links always visible in the site header.
_Avoid_: Full sitemap, mega menu

**Secondary Menu**:
A configurable dropdown inside the Main Navigation, labeled “More”, for less prominent internal or external links.
_Avoid_: Sidebar, mega menu

**Sidebar TOC**:
A table of contents shown beside a Post on larger screens.
_Avoid_: Inline outline, mobile TOC

**Site Chrome**:
The shared interface content around Posts, such as navigation, labels, and footer text.
_Avoid_: UI copy, template text
